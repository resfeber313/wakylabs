# Waky Labs — System Design Studio Website

A modern, animated website for Waky Labs, a system design studio.

## Features

- **Smooth Animations** — Floating orbs, parallax cards, scroll reveals
- **Responsive Design** — Works perfectly on desktop, tablet, and mobile
- **Interactive Elements** — Hover effects, tilt cards, ripple buttons
- **Performance Optimized** — Uses CSS transforms and Intersection Observer
- **Accessible** — Respects `prefers-reduced-motion`

## File Structure

```
waky-labs/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # All styles
├── js/
│   └── main.js         # All interactivity
└── assets/             # Add your images here
```

## How to Use

1. Extract the ZIP file
2. Open `index.html` in any modern browser
3. Or deploy to any static hosting (Netlify, Vercel, GitHub Pages, etc.)

## Customization

- **Colors**: Edit CSS variables in `:root` inside `css/style.css`
- **Content**: Update text directly in `index.html`
- **Fonts**: Currently uses Google Fonts (Space Grotesk + Inter)

## Browser Support

- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+
